# Changelog

## 0.1.0

First release (MVP).

- Tree view in the Activity Bar with status groups (running / waiting / idle / stale) and badge
- Claude Code provider: transcripts, process registry, optional hooks
- Hook installer with diff, confirmation and backup; documented status layer under `~/.session-radar`
- Click focuses or resumes sessions; context menu (rename, archive, transcript, …); workspace filter
- Codex provider as a skeleton
