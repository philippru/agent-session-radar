# Changelog

## 0.1.0

Erste Version (MVP).

- Tree View in der Activity Bar mit Statusgruppen (läuft / wartet / idle / alt) und Badge
- Claude-Code-Provider: Transkripte, Prozessliste, optionale Hooks
- Hook-Installer mit Diff, Bestätigung und Backup; dokumentierte Statusschicht unter `~/.session-radar`
- Klick fokussiert oder setzt Sessions fort; Kontextmenü (umbenennen, archivieren, Transkript, …); Workspace-Filter
- Codex-Provider als Skelett
